## Phase 2: Backend Hardening (Commits 5-9)

### Commit 5: `fix: handle missing prompt gracefully in request_analysis.py`
**Problem:** `load_prompt()` throws `FileNotFoundError` if prompt file is missing.
**Files:**
- `backend/request_analysis.py` — add fallback prompt string when file is missing

### Commit 6: `fix: remove bare except in report_builder.py and add structured logging`
**Problem:** `report_builder.py` has `except:` clause that silently swallows all errors from Moltbook publisher.
**Files:**
- `backend/report_builder.py` — replace bare `except:` with specific exception handling, add logging

### Commit 7: `feat: add pipeline error recovery and skip-on-failure`
**Problem:** If any pipeline step fails, subsequent steps crash. No resilience.
**Files:**
- `backend/agent.py` — wrap each step in try/except with logging, continue pipeline on non-fatal failures

### Commit 8: `feat: add /api/health endpoint`
**Problem:** No way to check agent health without hitting the heavy forensics endpoint.
**Files:**
- Create `api/health.py` — lightweight endpoint returning last scan time, token count, system status

### Commit 9: `feat: add SoSoValue API caching layer`
**Problem:** `/api/sosovalue` hits the external API on every request — will get rate-limited fast.
**Files:**
- `api/sosovalue.py` — add 5-minute TTL cache using in-memory dict (simple approach for serverless)

**Files:**
- `contracts/AegisAgent.sol` — replace `.transfer()` with `.call{value:}("")` pattern in `subscribe()` and `withdraw()`

### Commit 17: `fix: add subscription fee upper bound`
